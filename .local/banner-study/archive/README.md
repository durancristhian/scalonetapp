# Banner refinement prototype archive

Question: can the current banner read more like fabric while keeping the approved composition and terrain-specific irregularity?

Explored: option A softens the material with broader folds; option B retains the existing fabric treatment and adds corner creases and visible ties.

Decision approved on 2026-10-21: option B, removing only the two upper-corner ropes and knots. Preserve the eyelets, corner creases, silhouettes, hems, colors, and existing composition. The implementation needs only the added corner creases because ropes were never part of the production component.

Open `approved.html` directly to see the chosen result in all three terrains. Open `explored-alternatives.html` for the original comparison. Both files are self-contained and use synthetic fixtures. TSX snapshots preserve the prototype source outside the implementation branch.
